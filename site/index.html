Arch Setup for Mac

Arch Linux ARM on Apple Silicon Macs, in one command: QEMU + HVF, LUKS2-encrypted btrfs, and an integrity seal checked before every boot.

Install

bash <(curl -fsSL https://arch.arifcinartekin.me/install)

Uninstall

bash <(curl -fsSL https://arch.arifcinartekin.me/uninstall)

Source, documentation and pinned versions: github.com/arifcinartekin/archsetupformac
